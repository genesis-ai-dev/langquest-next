# Suggested update for LAN-227 (for Caleb to paste; the board's rules keep Claude out of Linear)

Title: Tailored data export for an organization that needs one

- Orgs already have the data API. A general "Export all data" button is not needed now.
- Build a tailored export only when a specific organization asks. Before building, get from them the exact formats they need (audio layout, file names, spreadsheets, raw history or not).
- The export lives apart from the phone's USB backup. That feature is unrelated and stays untouched.
- The earlier design notes (zip made on the server, signed link, format doc, fixture test, decision entry) stay as a starting point once an organization's formats are known.
