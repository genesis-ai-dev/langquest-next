What this mock is enforcing

  1. Words are optional on every U screen. The only text a translator reads is a passage reference. Instructions are audio: the walkthrough plays, it doesn't get explained. Labels here sit in accessibilityLabel, matching ActionButton's icon-only U variant.
  2. One yellow at a time, in production, derived from workflow.ts — never a stored status column, so a take syncing in from another device moves the yellow without a migration.
  3. The VAD session takes the whole screen. Ported from FullScreenVADOverlay and WaveformVisualization: a 60-bar ring buffer, white bars where isRecording was true and translucent where it was only monitoring, and a discarded segment reverts its bars. The screen is red for the whole session so "you are recording" is unambiguous and stable; capturing versus ignoring is a one-step lift in the ground plus solid bars, not a colour flip. The cutoff is a line you drag across the waveform — never a number — so "keep sound above this" is the whole instruction, and a segment under 200 ms is dropped rather than carded.
  4. Record is a mode, so it gets a mode control. The yellow bar means "one step forward"; a circular hold-to-record button means "this is running now". Breaking the bar pattern here is deliberate — it is the one gesture every user already knows, and IconCircleButton and QuestAssets already ship it.
  5. Colour is never alone. Every tile pairs its hue with its Lucide icon, and blocked state adds a struck-through mic rather than only fading.
  6. Blocked stays on screen. Hand-off is greyed in place and the checklist above it shows the one unmet condition as an icon — the grid never changes shape between passages.
  7. Progress is cross-session. The key-terms ring counts terms with audio anywhere in the project, so a returning translator sees credit for last week without reading a report.
  8. Structure is a template, not a schema. "Bible book" generates passages as ordinary project nodes; another org picks another template and gets the same U slideshows underneath.
