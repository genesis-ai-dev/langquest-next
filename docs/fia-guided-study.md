# FIA guided study

Managers select FIA from the reference library. The included pericope catalog
comes from the existing LangQuest catalog data. Selecting a passage chooses
the FIA content template for that language and adds its book and passage.
Existing units and recordings remain in the project.

The study template provides six fields: Hear, Stage, Scenes, Embody, Gaps,
and Speak. Managers supply the team's authorized study text and record spoken
instructions in the participants' language. The app does not bundle licensed
FIA lessons. Language guidance applies to all passages in that language;
passage study material applies only to its passage and descendants.

Participants open the FIA book button from the passage workflow. The drawer
shows one stage at a time, plays supplied instructions, and keeps the source
audio available during Hear. Speak opens the passage recorder. Opening that
recorder does not mark a recording complete.

Stage completion uses the existing material event stream, with separate
fields for each participant and passage. It syncs through the same offline
queue as other project work. The manager seeds a separate progress material,
so locking study guidance does not lock participant progress. Participants
need Fill Reference permission to save progress; the standard translator
role includes it. Viewers can browse without changing project data.

The existing FIA study fields remain supported: summary supplies Hear,
key_ideas supplies Stage, scenes supplies Scenes, and discussion supplies
Gaps. New templates use the six explicit stage fields.

Before release, verify on iPhone and Android that recording instructions
survives interruption, the drawer handles system back gestures, and spoken
guidance is understandable without relying on the stage labels.
