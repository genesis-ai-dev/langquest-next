# Films for the Benin trial (LAN-150)

For Jenn, who takes LangQuest to Benin in early December. Some people there
already have projects in the original app, so the first film shows what they
see once their work has come across. People in Benin mostly read French, so
each film has a French link beside the English one.

Every link below is a lasting link (decision 187): it follows each new
version of the film by itself, so it can be saved or sent as it is. Checked
on 2026-11-06: each answers with the film's file. Nothing here publishes or
changes a film.

## Waiting for Caleb

Only English is filmed each night until Caleb has looked at the films
(LAN-208, `docs/tutorial-videos.md`), so **every English film below still
waits for his approval**, and so does the new film, which is not filmed yet:
the nightly run films it once this change is merged. The French links point to
films made before the nightly run went English only.
